Mail-Cal 2.3.1 for Windows 10/11 (x64).

## What's new
- **Event details at a click.** Click an event in the calendar to see its time, location, organizer and calendar in a popup. Join an online meeting from there, or choose *View event* to open it. Double-click still opens the event directly.
- **See busy days in the tray.** The tray calendar marks days that have events with colored dots, and meetings with an online link get a *Join* button in the day list.
- **Know which address got it.** Recipients that are you now show which of your addresses received the message, such as "You <alex@contoso.com>" (from upstream Wino Mail [#1149](https://github.com/bkaankose/Wino-Mail/issues/1149)).

## Install
The package is signed with a self-signed Mail-Cal certificate, so Windows needs to trust it once. If you installed 2.3.0 already, the certificate is trusted and you can double-click the `.msixbundle` to update.

1. Download `MailCal_2.3.1.0_x64.msixbundle`, `MailCal.cer` and `Install-MailCal.ps1` into the same folder.
2. Open PowerShell in that folder and run:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Install-MailCal.ps1
   ```
   Approve the administrator prompt; it adds the certificate to *Trusted People*. Then the script installs Mail-Cal for your user.

Manual alternative: import `MailCal.cer` into **Local Machine > Trusted People** (`certlm.msc`), then double-click the `.msixbundle`.
