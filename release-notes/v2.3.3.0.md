Mail-Cal 2.3.3 for Windows 10/11 (x64).

## What's new
- **The envelope icon is back.** Mail-Cal uses the blue envelope icon again in the taskbar, the tray, the window title bar, the Start menu and its tiles. Windows caches app icons, so if you still see the old "MC" icon after updating, unpin and pin Mail-Cal again or restart your PC.

See [2.3.2](https://github.com/hairokuma/Mail-Cal/releases/tag/v2.3.2.0) and [2.3.1](https://github.com/hairokuma/Mail-Cal/releases/tag/v2.3.1.0) for the other recent changes.

## Install
The package is signed with a self-signed Mail-Cal certificate, so Windows needs to trust it once. If you installed an earlier Mail-Cal release, the certificate is trusted and you can double-click the `.msixbundle` to update.

1. Download `MailCal_2.3.3.0_x64.msixbundle`, `MailCal.cer` and `Install-MailCal.ps1` into the same folder.
2. Open PowerShell in that folder and run:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Install-MailCal.ps1
   ```
   Approve the administrator prompt; it adds the certificate to *Trusted People*. Then the script installs Mail-Cal for your user.

Manual alternative: import `MailCal.cer` into **Local Machine > Trusted People** (`certlm.msc`), then double-click the `.msixbundle`.
